      このアプリについて

      使い方

      • メイン画面のタイトルボタンをワンタップすると、 その瞬間の日時が履歴に記録されます。
      • 記録ボタンの追加・並び替え・削除は 「設定 → タイトル」で行います。
      • 「設定 → タイトル」でデフォルトに指定したタイトルは、 サイトを開いたときに自動で 1 回だけ記録されます (誤記録は トーストの「取り消す」または履歴の「削除」で戻せます)。
      • 履歴の各行から「編集」「削除」ができます。 編集画面では「現在時刻に戻す」も使えます。
      • バックアップが必要なときは「設定 → データ → JSONエクスポート」を 使ってください。記録に加えてタイトルや自動保存の設定も書き出され、 「JSONインポート」で復元・統合できます (同じ記録は重複せず取り込まれます)。
      • ホーム画面に追加するとアプリのように使えます。

      データと注意

      • ソースコードは GitHub で公開されています。
      • 記録はこのブラウザの localStorage にのみ保存されます。 端末を変えると引き継がれません。サーバー送信もありません。
      • タイトルには 個人情報・機密情報を入力しないでください。 ブラウザ拡張や端末を共有する他者から見える可能性があります。
